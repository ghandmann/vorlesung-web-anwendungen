# Technologie

- Backend:
    - Sprache: JavaScript (Node.js)
    - Framework: Express
- Frontend: 
    - Sprache: HTML5, CSS, JS, AJAX, JSON, jQuery, Bootstrap
    - Kein Angular/React → KISS
- Datenbank: SQLite
- Deployment: Express Development Server
- IDE-Vorschlag: VSCode 
- Versionskontrolle: Git, GitHub.com
