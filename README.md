# Vorlesung Web Anwendungen

Das ist das companion repository für die Vorlesung "Web Anwendungen" an der Hochschule Albstadt-Sigarmingen.

## Abgrenzung Web Anwendungen 1+2
Bis zum Wintersemester 2025/2026 war die Veranstaltung aufgeteilt in zwei Vorlesungen im dritten und vierten Semester.

Seit dem Sommersemester 2026 wurden beide Veranstaltungen in der Vorlesung "Web Anwendungen" vereint. Dabei sind die Inhalte aus Web Anwendungen 2 komplett übernommen worden (Backend zentriertheit) während die Inhalte aus Web Anwendungen 1 (HTML, CSS, JavaScript) im wesentlichen jetzt vorrausgesetzt werden.
